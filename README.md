# SplitLab
An A/B testing and causal inference platform for product decisions.

## Status
🚧 In progress - built phase by phase. Full write-up coming once complete.

## Overview
SplitLab evaluates whether a product change should ship, using experiment design, causal inference, and sequential/Bayesian analysis, with a FastAPI backend and a React dashboard.

## Stack
Python (numpy, pandas, scipy, statsmodels, lightgbm) · FastAPI · React · Docker
